# Internet Speed Test Script

Консольный скрипт на Python для замера скорости скачивания данных.
Делает 10 последовательных запросов к указанному URL, дожидается полного
ответа на каждый запрос, вычисляет среднее время, общий объём и скорость
скачивания.

## Единицы измерения скорости

В выводе скрипта используются две единицы:

1. **Mbps (Мегабит в секунду)** — стандартная единица для измерения пропускной
   способности сети (используется интернет-провайдерами).
2. **MB/s (Мегабайт в секунду)** — реальная скорость скачивания файлов
   (1 Байт = 8 бит).

## Требования

- Python 3.8+
- pip

## Установка

1. Клонируйте репозиторий:

   git clone https://github.com/kentuha38rus/internet-speed-test.git
   cd internet-speed-test

2. Создайте и активируйте виртуальное окружение:

   python -m venv venv
   venv\Scripts\activate      # Windows
   source venv/bin/activate   # macOS/Linux

3. Установите зависимости:

   pip install -r requirements.txt

## Запуск

Скрипт поддерживает два режима.

### Режим 1 — интерактивный (без аргументов)

    python main.py

Скрипт спросит, что тестировать:

    1 — стандартную картинку (NASA Black Marble, ~40 МБ)
    2 — свой URL картинки

Введите `1`, чтобы прогнать тест на встроенной картинке, или `2` — чтобы
ввести свой URL (должен начинаться с http:// или https://).

### Режим 2 — сразу с URL (для скриптов и CI)

    python main.py https://svs.gsfc.nasa.gov/vis/a030000/a030800/a030877/frames/5760x3240_16x9_01p/BlackMarble_2016_928m_india.tif

## Почему в запросе передаются заголовки

CDN и серверы (NASA SVS, Wikimedia, wallpaperscraft и др.) часто блокируют
запросы со стандартным User-Agent библиотеки requests, возвращая 403
Forbidden. В скрипте передаётся User-Agent реального браузера, чтобы
получить доступ к файлу.

## Особенности работы на Windows с Python 3.13

В Python 3.13 на Windows ужесточена проверка SSL-сертификатов. В виртуальном
окружении (venv) Python может не иметь доступа к системному хранилищу
сертификатов Windows, из-за чего возникают ошибки вида:

    CERTIFICATE_VERIFY_FAILED: unable to get local issuer certificate

Решение: пакет pip-system-certs уже включён в requirements.txt.
Он автоматически подключает системные сертификаты Windows к Python.
Если вы ставили зависимости вручную и пропустили его — установите отдельно:

    pip install pip-system-certs

После установки перезапустите терминал и активируйте venv заново.
Пакет не требует изменений в коде и не создаёт .pth-файлов с ошибками.

## Примечание о размере файла и таймауте

В примере используется мозаика NASA Black Marble (TIF, ~40 МБ). В скрипте
установлен timeout=300 секунд — с запасом на медленные каналы. Скрипт
загружает файл в память целиком (через response.content), поэтому для
очень больших файлов нужно достаточное количество ОЗУ (порядка размера
файла на одну итерацию). Если требуется работа с файлами в сотни МБ —
лучше перейти на потоковую загрузку response.iter_content(chunk_size=...).
